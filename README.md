# SWYNEX Final Data Analytics Project

## 1. Project Overview
This project was completed as part of the SWYNEX Technologies Data Analyst Internship.

The project focuses on analyzing customer sales data using Python and Microsoft Power BI to understand customer behavior and present useful business insights.

## 2. Problem Statement
Businesses need to understand their customers, purchasing patterns, and feedback to make better decisions.

This project analyzes customer sales data to identify useful patterns and present the results through an interactive dashboard.

## 3. Dataset Information
The project uses a customer sales dataset containing 10,014 records and 12 columns.

The dataset includes information such as:
- Customer ID
- Gender
- Age
- Purchase Amount
- Feedback Score
- Country
- City
- Signup Date
- Last Purchase Date

## 4. Data Cleaning and Preparation
The data cleaning process was completed using Python.

The work included:
- Inspecting the dataset
- Identifying missing values
- Checking duplicate records
- Checking data types
- Preparing the cleaned dataset for analysis

## 5. Exploratory Data Analysis
Exploratory Data Analysis (EDA) was performed using Python.

The analysis explored:
- Customer information
- Purchase amounts
- Gender distribution
- Age distribution
- Customer locations
- Feedback scores

## 6. Interactive Dashboard
An interactive dashboard was developed using Microsoft Power BI.

### Key Performance Indicators
- Total Customers
- Total Sales
- Average Purchase
- Average Age

### Visualizations
- Customers by Country
- Gender Distribution
- Age Distribution
- Feedback Score Distribution

### Interactive Filters
- Country
- Gender
- Age

## 7. Key Business Insights
The dashboard helps users explore:
- Customer distribution across countries
- Differences in customer demographics
- Customer purchase patterns
- Customer feedback distribution

These insights can support business decision-making and customer analysis.
